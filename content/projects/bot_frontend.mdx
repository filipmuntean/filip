I am currently developing the front end for the **Rolo-tutor project**, a chatbot-based educational tool, built specifically for teaching Python, using **React** and **chart.js** among others.

### My Tasks Involve:

- **Microsoft OAuth 2.0 Integration**: I am implementing user authentication using Microsoft OAuth 2.0, ensuring secure access to the chatbot for authenticated users only.
- **User-Friendly Interface**: I am building a dynamic interface to facilitate interactions, including the development of modal forms for student feedback submission.
- **Developer Dashboard**: I am creating a dashboard that allows developers to visualize and analyze student feedback effectively. 
    - In the dashboard, I have also done topic clustering, to group together related questions, which are visualied in a bubble chart which can be clicked to access each cluster as a table. 
    - I have also implemented some charts via [chart.js](https://www.chartjs.org/) to visualize traffic and number of messages per day 
- I have also deployed the web app on Google Cloud Platform via a Docker image.
